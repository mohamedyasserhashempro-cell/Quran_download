# Quran_download| Quran Recitation Platform

An Arabic Quran recitation and Islamic content platform designed to make Quranic content easier to explore and access.

## 📌 About the Project

Wortel Quran is a web design project featuring an Arabic right-to-left (RTL) interface, a dark visual theme, and organized content sections.

The platform showcases Quranic content, reciters, and Islamic educational topics through image-based cards.

## ✨ Features

- Arabic RTL layout.
- Dark-themed user interface.
- Blue navigation header.
- Organized Islamic content sections.
- Quran reciter cards.
- Image-based navigation.
- Responsive presentation concept.

## 🎨 Design

The design focuses on simplicity, readability, and visual organization while maintaining an Islamic-inspired identity.
